# 2026-09-09 — 적 AI 1차 완성 (오빗 이동 + 비헤이비어 셸 + 스쿼드)

[2026-09-02.md](2026-09-02.md) "남은 것"의 **적 AI**와 **사망 처리**를 한 번에.
새로 쓴 지침서 [beat_em_up_enemy_ai_guide.md](beat_em_up_enemy_ai_guide.md)(Boghog 자료 정리)를 따라
**한 기능 → 테스트 → 다음 기능 → 마지막에 조립** 방식으로 10단계에 걸쳐 진행했다.

몸 쪽(`Actor` 이하)은 `CharacterState.Dead` / `IsHitStunned` 두 개만 추가하고 나머지는 무변경 —
적 AI는 전부 `EnemyBrain : IIntentSource` 안쪽과 새 컴포넌트에만 들어갔다.

| 아키타입(성향) | `EnemyArchetype` ScriptableObject (가중치 5개) | AttackData와 같은 패턴. 재사용·중앙 정의 |

| 사망 연출 | 넉다운 후 N초 뒤 `Destroy` (적 전용 `EnemyDespawn`) | 플레이어 사망 = 게임오버라 공용 처리 아님 |

> 결정 지점 랜덤성은 셀렉터로 흡수됐다. 옛 3번이 사라지고 이후 번호가 당겨짐.

## 핵심 구조

**위상 머신 (`EnemyBehavior`):** 모든 노드가 `Startup`(정지+주시) → `Active`(min~max, `OnTick`) →
`Recovery`(정지+주시) → `Done`. `maxActiveDuration`이 있어 `WantsToExit`가 영영 안 떠도 반드시 끝난다
— "조건 대기만으로 끝나는 노드" 구조적 불가능 (지침서 3장 타이머 강조).

**[reset] 패턴 (`EnemyBrain`):** 행동 전환 시 `current`를 직접 안 바꾸고 `desired` 세팅 → `RunReset`이
`previous` 기록 + `current = desired` + `Enter()`. `current` 재할당은 `RunReset` 한 곳뿐.

**히트스턴 재판단:** `GetIntent`가 `IsHitStunned` 중이면 노드 `Tick`을 아예 안 해 위상 타이머가 멈춘다
(얻어맞는 동안 행동 시간이 소모되지 않음). 이탈한 첫 프레임에 `Exit` + `Decide` + `[reset]` 강제 →
텀 없이 즉시 새 결정. 지침서 5장: 이 텀이 사실상 무한 콤보가 된다.

**블랙보드 (`SquadController` → `EnemyBrain`):** 스쿼드가 멤버를 현재 각도로 정렬해 `360/N` 간격 슬롯을
`member.SlotAngle`에 write(교차 방지), `ApproachBehavior`가 read. 공격은 토큰(`maxSimultaneousAttackers`).
스쿼드 없으면 각 적 솔로 — 1~8단계가 그대로 성립.

**성향 = 가중치 (`EnemyArchetype`):** `Awake`의 `ApplyArchetype`이 5개 값을 각 행동 `selectionWeight` +
`selector.dryFireWeight`에 복사. 새 행동·셸 코드 0.

## 몸 쪽 변경 (최소)

| 파일 | 변경 |
|---|---|
| `CharacterStateMachine` | `Dead` 상태(종착 sticky — 워치독·`Interrupt`·`Evaluate` 모두 제외) + `EnterDead` + `IsHitStunned` |
| `Health` | `IsDead` 프로퍼티 · 사망 시 `EnterDead()` 호출 |
| `Actor` | `Update` 맨 앞 `Dead` 가드 (공중이면 `locomotion.Tick`만) |

## 남은 것 / 알려진 한계

- **원거리 공격** — `Fighter`는 근접 전용. 투사체 경로 없음 ([2026-09-02.md](2026-09-02.md)에서 이월)
- **궤도 반경 보정** — 화면 좌우 끝 부근에서 궤도가 맵 밖을 가리키면 `Locomotion` 클램프에 의존(벽 밀착).
  지침서 2장의 "궤도 위에 별도 충돌 회피"는 미구현
- **z축 공격 판정 폭** — `Fighter.PerformHitScan`이 `OverlapSphere` 그대로. 명시적 레인 허용치 없음 (지침서 6장)
- **잡기/던지기** — 지침서 1.1이 공용 부모에 두라는 항목. 미구현
- **`EnemyOrbitMovement` 드리프트** — 이동 잠금(공격 중) 사이에도 `CurrentAngle`이 굴러가 잠금 풀리면
  한 번에 붙음. 노드가 잠금 상태를 몰라서 — 지금은 짧아서 무시 가능
- **EnemyArchetype 에셋** — 스크립트만. 실제 성향 `.asset`은 아직 안 만듦

## 유지할 것

- **Intent 패턴** — 브레인을 갈아엎어도 `Actor` 무변경이 이번에 실증됨
- **독립 테스트 가능한 노드** — Enter/Tick/Exit + 위상 타이머가 "독립"의 실질 기준
- **몸 계층 워치독의 AI판** — `maxActiveDuration`으로 노드가 반드시 끝남
- **배타적 상태는 enum** — `EnemyBehavior.Phase`
- **디버그 표시는 Test/에 독립 컴포넌트** — `Enemy*DebugDisplay` 3종, 파일+컴포넌트 제거로 떼어냄
