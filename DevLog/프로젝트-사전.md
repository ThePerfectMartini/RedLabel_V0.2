# 프로젝트 사전

이 프로젝트 코드에 나오는 **모든 함수·프로퍼티·이벤트**를 파일별로 정리한 레퍼런스.
"누가/언제 호출"은 실제 호출 지점 기준. 구조가 바뀌면 이 문서도 같이 고칠 것.

- `(k)` = Unity 매직 메서드 (Unity가 자동 호출)
- `[SO]` = ScriptableObject 에셋 필드 (인스펙터에서 채움)
- `▶` = public / `·` = private / `◆` = 인터페이스 멤버

작성 기준: 적 AI 1차 완성 (2026-09-09) — 사망 처리 · 타깃 획득 · 오빗 이동 · 브레인 셸 · 리프 노드 ·
확률 셀렉터 · 히트스턴 재판단 · 스쿼드 컨트롤러 · 아키타입 반영

## 0. 아키텍처 한눈에

```
IIntentSource (PlayerInput / EnemyBrain)
      │ GetIntent(dt) → CharacterIntent
      ▼
   ┌─────┐   매 프레임 유일한 Update. 순서를 한 곳에 고정.
   │Actor│──────────────────────────────────────────────┐
   └─────┘                                               │
      │ 호출 (순서: 방어 → 공격 → 점프 → 이동)             │
      ├──▶ Dodger.TryDodge / Tick   (없으면 건너뜀)        │
      ├──▶ Parrier.TryParry / Tick  (없으면 건너뜀)        │
      ├──▶ Fighter.TryAttack / Tick                       │
      ├──▶ Locomotion.SetFacing / SetMoveInput / Tick     │
      └──▶ CharacterStateMachine.Enter* / Evaluate        │
                                                          │
  Fighter  ──▶ Locomotion (StopGroundSlide, ApplySelfMovement)
  Fighter  ──▶ CharacterStateMachine (EnterAttack/ExitAttack, CanAct 읽기)
  Health   ──▶ Locomotion (ApplyKnockback) + StateMachine (Interrupt) + Fighter (CancelAttack)
  Health   ──▶ Parrier.IsParryWindowActive / NotifyParried · Dodger.IsInvulnerable / NotifyDodgedAttack (피격 가로채기)
  Dodger   ──▶ Fighter (CancelAttack) + Locomotion (ApplyKnockback 대시) + StateMachine (EnterDodge/ExitDodge)
  Parrier  ──▶ StateMachine (EnterParry/EnterParrySuccess/ExitParry) + 공격자의 IHittable.OnHit (데미지 0 → Stun)
  StateMachine ──▶ Locomotion (읽기 전용 + 점프발사 시 Jump() 1건)

  [Visual 자식] AnimationEventRelay ──▶ Fighter / CharacterStateMachine  (클립 이벤트 중계)

  다른 Actor의 Fighter.PerformHitScan ──▶ 이 Actor의 Health.OnHit  (교차 오브젝트, IHittable)
  Parrier.NotifyParried ──▶ 공격자의 Health.OnHit  (교차 오브젝트, 데미지 0짜리 HitData)

  [적 전용] EnemyBrain(IIntentSource) ── EnemyTargeting(대상) · EnemyOrbitMovement(궤도 이동) · EnemyBehavior 노드들
           SquadController ──▶ 각 EnemyBrain의 블랙보드(SlotAngle / 공격 토큰)   ← 개별 트리 바깥
```

`Locomotion`이 그래프의 종점(아무도 호출 안 받음, 아무도 호출 안 함 — Jump 예외 1건).
`Dodger` / `Parrier`는 플레이어만 가짐 — `Actor` · `Health`가 `GetComponent`로 찾고 없으면 조용히 건너뜀.
적 AI(EnemyBrain 계열)는 §7.5. `Actor`는 `IIntentSource` 계약만 알고 그 안을 모른다.

## 1. Actor — `Assets/Script/Character/Actor.cs`

캐릭터 "몸"을 조율. **몸 컴포넌트 중 유일하게 `Update()`를 가짐.**
`[RequireComponent(Locomotion, Fighter, CharacterStateMachine)]` + `[RequireComponent(Health)]`

| 멤버 | 시그니처 | 누가/언제 | 하는 일 |
|---|---|---|---|
| · `Awake` | `(k)` | Unity | `GetComponent`로 locomotion/fighter/stateMachine/intentSource + **dodger/parrier**(없어도 OK — 플레이어만) 캐싱. intentSource 없어도 OK (훈련 더미) |
| · `Update` | `(k)` | Unity 매 프레임 | **`stateMachine.CurrentState == Dead`면 조기 반환** (공중이면 `locomotion.Tick`만 굴려 바닥까지 떨어뜨림). 아니면 순서 고정: ① `intentSource.GetIntent(dt)` ② 방향 잠금 계산 → `locomotion.SetFacing` ③ `intent.WantsDodge` → `dodger?.TryDodge()` ④ `intent.WantsParry` → `parrier?.TryParry()` ⑤ `fighter.TryAttack` ⑥ `EnterJumpStart` + `locomotion.PrepareJump` ⑦ 이동 잠금 재계산 → `locomotion.SetMoveInput` ⑧ 착지 엣지용 값 스냅샷 ⑨ `locomotion.Tick` ⑩ `EnterJumpLand`/`EnterLanded` 엣지 판정 ⑪ `fighter.Tick` → `dodger?.Tick` → `parrier?.Tick` ⑫ `stateMachine.Evaluate` |

> **방향은 공격 전, 이동은 공격 후** 잠금을 계산한다 → "→+X 동시 입력 시 오른쪽으로 공격"이 여기서 나옴.
> **방어(회피·패링)는 공격보다 먼저** 처리한다 → 같은 프레임에 방어와 공격이 같이 눌리면 방어 우선.
> **죽으면 판단·공격·이동을 전부 멈춘다** — `Dead` 가드가 Update 맨 앞. 소멸은 `EnemyDespawn`(§7.5).

## 2. Locomotion — `Assets/Script/Character/Locomotion.cs`

Rigidbody 없이 위치/속도를 직접 적분. `[RequireComponent(Collider)]`

### enum `AirborneOrigin { None, Jump, Knockback }`
공중에 뜬 이유. 진입점이 `Jump()`/`ApplyKnockback()` 둘뿐이라 출처가 항상 셋 중 하나. 착지하면 `None`.

### 직렬화 필드
| 필드 | 타입 | 설명 |
|---|---|---|
| ▶ `movementStatData` | `MovementStatData` [SO] | Awake에서 스탯 복사. 없으면 코드 기본값 |
| ▶ `use8DirectionSnap` | `bool` | 켜면 45도 스냅(플레이어), 끄면 입력 방향 그대로(AI) |
| ▶ `MoveSpeedMultiplier` | `float` field | Actor가 매 프레임 `fighter.MoveSpeedMultiplier`로 설정 |

### 읽기 프로퍼티 (외부가 상태 조회)
| 프로퍼티 | 타입 | 주 소비자 | 의미 |
|---|---|---|---|
| ▶ `Velocity` | `Vector3` | — | 현재 속도 |
| ▶ `IsGrounded` | `bool` | Actor, StateMachine | 지상 여부 |
| ▶ `IsGroundSliding` | `bool` | StateMachine (`Stun` 판정) | 넉백 히트슬라이드 중 |
| ▶ `IsKnockedBackAirborne` | `bool` | Actor(엣지), StateMachine(`Airborne`) | `origin == Knockback` |
| ▶ `LaunchedByJump` | `bool` | Actor (착지 경직 엣지) | `origin == Jump` |
| ▶ `HorizontalSpeed` | `float` | StateMachine (`Move`/`Idle` 판정) | 수평 속력 |
| ▶ `FacingRight` | `bool` | StateMachine (스프라이트 flipX) | 바라보는 좌우 |
| ▶ `FacingDir` | `Vector3` | Fighter (히트스캔 방향), StateMachine | `right` 또는 `left` |

### 메서드
| 메서드 | 시그니처 | 누가/언제 | 하는 일 |
|---|---|---|---|
| · `Awake` | `(k)` | Unity | SO 값 복사 + `Collider.bounds.extents`로 boundaryRadius/groundOffset 계산 |
| ▶ `SetMoveInput` | `(Vector2 rawInput)` | Actor 매 프레임 | 수평 속도 갱신. **공중이거나 슬라이드 중이면 무시**. 8방향 스냅 or 정규화 |
| ▶ `SetFacing` | `(Vector3 direction)` | Actor 매 프레임 | x 성분만 보고 좌우 결정. **지상에 있을 때만**. 0 벡터면 무시(잠금 시 Actor가 0을 넘김) |
| ▶ `SnapTo8Directions` | `static (Vector3) → Vector3` | `SetMoveInput` 내부 | 임의 방향 → 45도 단위 8방향 스냅 |
| ▶ `PrepareJump` | `(float horizontalInputX)` | Actor (점프 의도 순간) | 아직 안 뜸. 이 순간의 좌우 속도만 기억 |
| ▶ `Jump` | `()` | **StateMachine.OnJumpLaunchFrame** | 실제 발사. `velocity.y = jumpForce`, `origin = Jump`. 지상 아니면 무시 |
| ▶ `ApplyKnockback` | `(Vector3 knockbackVelocity, float slideDeceleration)` | Health.OnHit, ImpulseAttackData.ApplySelfMovement | 수직 속도 > 임계값이면 공중으로(origin=Knockback), 이하이고 지상이면 그라운드 슬라이드. 진행 중 점프 무효화 |
| ▶ `StopGroundSlide` | `()` | Fighter (StartAttack/AdvanceOrEnd/CancelAttack) | 슬라이드 즉시 종료 + 수평 속도 0. 슬라이드 중 아니면 no-op |
| ▶ `Tick` | `(float deltaTime)` | Actor 매 프레임 | 슬라이드 감속 → 중력 → 위치 적분 → 바닥 충돌/바운스 → 맵 경계 클램프/바운스. `MapBounds.Instance`, `GlobalPhysicsData.Instance` 직접 읽음 |

## 3. Fighter — `Assets/Script/Character/Fighter.cs`

공격 하나(`AttackData`)를 실행. `IAttackRangeDebugInfo` 구현.
`[RequireComponent(Locomotion, CharacterStateMachine)]`

### 필드 / 이벤트
| 멤버 | 타입 | 설명 |
|---|---|---|
| ▶ `targetLayer` | `LayerMask` field | 때릴 대상 레이어 (플레이어→Enemy, 적→Player) |
| ▶ `OnAttackHitFrameFired` | `event Action` | 타격 판정 순간 발생. `AttackRangeGizmo`가 구독 |
| · `warned` | `static HashSet<AttackData>` | 에셋당 경고 1회 |
| · `hitThisScan` | `HashSet<IHittable>` | 한 스캔에서 대상 중복 타격 차단 (콜라이더 여러 개 대응) |

### 읽기 프로퍼티 (IAttackRangeDebugInfo 포함 — null 가드 있음: 에디트 모드 대비)
| 프로퍼티 | 타입 | 주 소비자 | 의미 |
|---|---|---|---|
| ▶ `IsAttacking` | `bool` | Fighter 내부, Gizmo | `stateMachine.CurrentState == Attack` (별도 플래그 없음) |
| ▶ `MovementAllowed` | `bool` | Actor (이동 잠금) | 공격 중이 아니거나, 그 공격이 이동 허용이면 true |
| ▶ `MoveSpeedMultiplier` | `float` | Actor | 공격 중이면 그 공격의 배율, 아니면 1 |
| ▶ `FacingDir` | `Vector3` | Gizmo | `locomotion.FacingDir` 위임 |
| ▶ `AttackRange` / `AttackRadius` | `float` | Gizmo, `PerformHitScan` | 현재 공격 값, 없으면 0 |

### 메서드
| 메서드 | 시그니처 | 누가/언제 | 하는 일 |
|---|---|---|---|
| · `Awake` | `(k)` | Unity | locomotion/stateMachine 캐싱 |
| ▶ `TryAttack` | `(AttackData requested)` | Actor (`intent.AttackToStart != null`) | **3갈래** — ① 공격 중 아님: `CanAct` + 쿨타임 통과 시 `StartAttack` ② 다른 공격: `canCancelOtherAttacks` && `hasFiredHitFrame`일 때만 즉시 캔슬 ③ 같은 공격: `nextAttack` 있으면 `comboBuffered = true` |
| ▶ `Tick` | `(float deltaTime)` | Actor 매 프레임 | 공격 중이면 `attackTimer` 감소, 0 이하 시 `AdvanceOrEnd` |
| ▶ `OnAttackHitFrame` | `()` | **AnimationEventRelay** (클립 타격 프레임) | `PerformHitScan` → `hasFiredHitFrame = true` → 이벤트 발생 |
| ▶ `CancelAttack` | `()` | Health.OnHit, **Dodger.StartDodge** | 타이머/콤보 예약/스타터/히트프레임 정리 + `StopGroundSlide`. **상태 전이는 안 함** (Health의 Interrupt / Dodger의 EnterDodge 담당) |
| · `StartAttack` | `(AttackData data)` | TryAttack, AdvanceOrEnd | `StopGroundSlide` → 타이머/쿨타임 설정 → `WarnIfMisconfigured` → `stateMachine.EnterAttack(clip)` → `data.ApplySelfMovement` |
| · `AdvanceOrEnd` | `()` | Tick (타이머 소진) | `comboBuffered` && `nextAttack` 있으면 다음 단계 `StartAttack`, 아니면 정리 + `stateMachine.ExitAttack` |
| · `PerformHitScan` | `()` | OnAttackHitFrame | `Physics.OverlapSphere(center, radius, targetLayer)` → 각 `col.GetComponentInParent<IHittable>()` (중복 제거) → `HitData` 만들어 `OnHit` |
| · `WarnIfMisconfigured` | `static (AttackData)` | StartAttack | 클립/지속시간 없음, `OnAttackHitFrame` 이벤트 없음을 에셋당 1회 경고 |

## 4. Health — `Assets/Script/Character/Health.cs`

체력 + 피격 처리. `IHittable` 구현.
`[RequireComponent(Locomotion, Fighter, CharacterStateMachine)]`

| 멤버 | 시그니처 | 누가/언제 | 하는 일 |
|---|---|---|---|
| ▶ `characterStatData` | `CharacterStatData` [SO] field | — | maxHealth 소스 |
| ▶ `CurrentHealth` | `int` prop (get) | HealthDebugDisplay | 현재 체력 |
| ▶ `MaxHealth` | `int` prop (get) | HealthDebugDisplay | `characterStatData.maxHealth` 또는 100 |
| ▶ `IsDead` | `bool` prop (get) | Actor(간접 — `Dead` 상태로), 외부 | `dead` 플래그 노출 |
| ▶ `OnDeath` | `event Action` | **EnemyDespawn**(적) | 체력 0 이하 순간 1회 |
| · `Awake` | `(k)` | Unity | 시블링 캐싱(+ dodger/parrier, 없어도 됨) + `CurrentHealth = MaxHealth` |
| ▶ `OnHit` | `(HitData hit)` ◆IHittable | **공격자의 `Fighter.PerformHitScan`** / **`Parrier.NotifyParried`**(데미지 0) | 앞에서부터 걸리면 그 프레임 피격 통째로 무시: ① `dead` → 무시 ② `parrier.IsParryWindowActive` → `parrier.NotifyParried(hit.Attacker)` 후 return ③ `dodger.IsInvulnerable` → `dodger.NotifyDodgedAttack(hit.Attacker)` 후 return ④ 통과 → 데미지 → `fighter.CancelAttack()` → `hit.ResolveKnockbackVelocity(!IsGrounded)` → `locomotion.ApplyKnockback` → `stateMachine.Interrupt()` → 0 이하 시 `dead = true` → **`stateMachine.EnterDead()`**(Interrupt 위를 덮음) → `OnDeath` |

## 5. CharacterStateMachine — `Assets/Script/Character/CharacterStateMachine.cs`

상태 enum 하나로 **논리 게이팅 + 애니메이션 + 워치독**. `[RequireComponent(Locomotion)]`

### enum `CharacterState`
| 그룹 | 값 | 진입 | 탈출 |
|---|---|---|---|
| 물리 파생 (`Evaluate`가 매 프레임 재계산) | `Idle` `Move` `InAir` `Stun` `Airborne` | Locomotion 상태에서 자동 | 자동 |
| 고정 sticky (명시적 호출/이벤트로만) | `JumpStart` | `EnterJumpStart` | `OnJumpLaunchFrame` |
| | `JumpLand` | `EnterJumpLand` (착지 엣지) | `OnJumpLandEndFrame` |
| | `Attack` | `EnterAttack` | `ExitAttack` (Fighter 타이머) — **워치독 제외** |
| | `Dodge` | `EnterDodge` | `ExitDodge` (Dodger 타이머) — **워치독 제외** |
| | `Parry` | `EnterParry` | `ExitParry` (Parrier 타이머) — **워치독 제외** |
| | `ParrySuccess` | `EnterParrySuccess` (패링 성공 순간) | `ExitParry` (Parrier 타이머) — **워치독 제외** |
| | `Landed` | `EnterLanded` (넉백 착지 엣지) | `OnKnockdownGetUpStartFrame` |
| | `GetUp` | (Landed의 이벤트) | `OnKnockdownGetUpEndFrame` |
| | `Dead` | `EnterDead` (Health 사망) | **없음 — 종착 상태** (워치독·Interrupt·Evaluate 모두 손 안 댐) |

### 필드 / 상수
| 멤버 | 타입 | 설명 |
|---|---|---|
| ▶ `transitionDuration` | `float` field (기본 **0**) | 애니메이션 블렌드 시간. 스프라이트는 보간 불가라 0. >0이면 `CrossFadeInFixedTime`, 0이면 `Animator.Play` 하드컷 |
| ▶ `actionPhaseTimeout` | `float` field (기본 2) | 워치독: 고정 상태가 이 시간 넘게 안 끝나면 강제 해제 |
| · `MoveEpsilon` | `const 0.1f` | 이 속력 이상이면 `Move` |
| · `warnedMissing` | `HashSet<string>` | 없는 Animator State 경고 1회 |

### 읽기 프로퍼티
| 프로퍼티 | 타입 | 주 소비자 | 의미 |
|---|---|---|---|
| ▶ `CurrentState` | `CharacterState` (get; private set) | 어디서나 | 현재 상태 |
| ▶ `CanAct` | `bool` | Actor(점프 가드), Fighter(새 콤보 가드), Dodger/Parrier(발동 가드) | 고정 상태(Attack·Dodge·Parry·ParrySuccess·**Dead** 포함)도 Stun도 Airborne도 아님 |
| ▶ `IsMovementLocked` | `bool` | Actor | JumpStart/JumpLand/**Dodge**/**Parry**/**ParrySuccess**/Landed/GetUp/Stun/Airborne/**Dead**. **Attack은 제외** (Fighter가 판단) |
| ▶ `IsHitStunned` | `bool` | **EnemyBrain** (히트스턴 재판단), 외부 | `Stun` / `Airborne` / `Landed` / `GetUp` 중 하나 — "얻어맞는 중" |

### 진입점 메서드
| 메서드 | 시그니처 | 누가/언제 | 하는 일 |
|---|---|---|---|
| ▶ `EnterAttack` | `(AnimationClip clip)` | Fighter.StartAttack | 상태 `Attack` + 클립 이름으로 CrossFade (콤보 단계마다 다른 클립) |
| ▶ `ExitAttack` | `()` | Fighter.AdvanceOrEnd | 지금 Attack이면 물리 파생 상태로 |
| ▶ `EnterJumpStart` | `()` | Actor (점프 의도) | 상태 `JumpStart` |
| ▶ `EnterJumpLand` | `()` | Actor (점프 착지 엣지) | 상태 `JumpLand` |
| ▶ `EnterLanded` | `()` | Actor (넉백 착지 엣지) | 상태 `Landed` |
| ▶ `EnterDead` | `()` | **Health.OnHit** (사망 순간) | 상태 `Dead`. 전용 "Dead" Animator State가 있으면 그쪽, 없으면 넉다운(`Landed`) 포즈로 CrossFade. 종착 — 탈출 메서드 없음 |
| ▶ `EnterDodge` | `()` | Dodger.StartDodge | 상태 `Dodge` (애니메이션은 "Dodge" State로 CrossFade) |
| ▶ `ExitDodge` | `()` | Dodger.Tick (타이머 소진) | 지금 `Dodge`면 물리 파생 상태로 |
| ▶ `EnterParry` | `()` | Parrier.TryParry | 상태 `Parry` |
| ▶ `EnterParrySuccess` | `()` | Parrier.NotifyParried (패링 성공) | 상태 `Parry` → `ParrySuccess` |
| ▶ `ExitParry` | `()` | Parrier.Tick (타이머 소진) | 지금 `Parry`/`ParrySuccess`면 물리 파생 상태로 |

| `OnGUI` | CharacterStateDebugDisplay, HealthDebugDisplay, FrameStepper, **EnemyTargetingDebugDisplay, EnemyBrainDebugDisplay, SquadDebugDisplay** | **플레이 모드 전용** (에디트 모드 안 돎) |
| `OnDrawGizmos` | AttackRangeGizmo | **에디트 모드에도 돎** → 참조 미해결 상태 대비 필요 |
| `OnDrawGizmosSelected` | MapBounds, BeltScrollCameraPivot, **EnemyTargeting** (대상까지 선), **EnemyOrbitMovement** (궤도 원) | 선택 시에만 |

## 14. Animation Event 함수 색인

클립에 심는 이벤트 → **Animator가 붙은 GameObject(Visual 자식)의 `AnimationEventRelay`** 가 받음 → 루트로 중계.

| 이벤트 이름 | 심는 클립 | 위치 | Relay가 넘기는 곳 | 최종 처리 |
|---|---|---|---|---|
| `OnAttackHitFrame` | 각 공격 클립 (Attack 1/2/3, 적 Attack) | 타격 프레임 | `Fighter.OnAttackHitFrame` | `PerformHitScan` (그 시점 위치/방향) |
| `OnJumpLaunchFrame` | JumpStart | 발이 떨어지는 프레임 | `CharacterStateMachine.OnJumpLaunchFrame` | `Locomotion.Jump()` |
| `OnJumpLandEndFrame` | JumpLand | 마지막 프레임 | `.OnJumpLandEndFrame` | 착지 경직 해제 |
| `OnKnockdownGetUpStartFrame` | Landed | 마지막 프레임 | `.OnKnockdownGetUpStartFrame` | Landed → GetUp |
| `OnKnockdownGetUpEndFrame` | GetUp | 마지막 프레임 | `.OnKnockdownGetUpEndFrame` | 기상 완료 |

`AttackData.HitFrameEventName`이 `nameof(AnimationEventRelay.OnAttackHitFrame)`으로 정의돼 있어, 릴레이 메서드 이름을 바꾸면 컴파일이 깨진다 (더 이상 매직 스트링 아님).

## 16. 명명 규칙 / 계약 (깨면 조용히 버그)

| 규칙 | 이유 |
|---|---|
| **Animator State 이름 == `CharacterState` 값 == 공격 클립 이름** | `CrossFade`가 문자열/해시로 매칭. 없으면 조용히 실패 → 경고 1회만 |
| **`AnimationEventRelay`는 Visual 자식(Animator 있는 곳)에** | 애니메이션 이벤트는 Animator의 GameObject로만 전달됨 |
| **스프라이트 애니메이션 클립: 원샷은 Loop Time 끄기, 전환 블렌드 0** | 스프라이트는 프레임 보간 불가. loop면 전환 지연 1프레임에 0프레임이 튀어나옴 |
| **인터페이스는 "어디 붙을지 모르는 것"에만** (IHittable=공격자≠대상, IAttackRangeDebugInfo=디버그 툴) | "항상 같이 붙는 컴포넌트 결합 제거"용 인터페이스는 만들지 않음 (구조 단순화) |
| **"진행 중 동작"(sticky: JumpStart/JumpLand/Attack/Dodge/Parry/ParrySuccess/Landed/GetUp) vs "물리적 사실"(Idle/Move/InAir/Stun/Airborne)** 구분 | sticky는 명시적 탈출, 물리 파생은 매 프레임 재계산. `Evaluate`가 sticky면 조기 반환 |
| **워치독 대상 = 애니메이션 이벤트로만 끝나는 sticky** (JumpStart/JumpLand/Landed/GetUp). Attack/Dodge/Parry/ParrySuccess는 각자 컴포넌트 타이머로 자력 종료 → **워치독 제외** | 타이머로 끝나는 상태는 이벤트 누락으로 갇힐 일이 없음 |
| **방어(Dodger/Parrier) 입력은 Actor에서 공격보다 먼저 처리** | 같은 프레임에 방어+공격이면 방어 우선 |
| **`Dodger`/`Parrier`는 옵션 컴포넌트** — `Actor`·`Health`가 null 체크 후 호출 | 적·더미엔 없음. `RequireComponent`로 강제하지 않음 |
| **`Locomotion`은 아무도 호출하지 않는다** (Jump 예외 1건) | 의존 그래프 종점. 이동 로직의 단방향 격리 |
| **캐릭터당 콜라이더 1개** (`targetLayer`에 포함되는) | 여러 개면 `OverlapSphere`가 그 수만큼 반환 → `OnHit` 중복 (Fighter가 방어는 하지만) |
| **적 AI는 `Actor`를 안 건드린다** — `EnemyBrain`이 `IIntentSource`로만 붙는다 | 브레인을 갈아엎어도 몸은 무변경 (지침서 1.1) |
| **`EnemyOrbitMovement`는 BT와 무관한 독립 모듈** — 행동이 `desiredAngle`/`orbitRadius`만 넘긴다 | "어떻게 그 위치로 가는가"를 노드에서 분리 (지침서 8.2) |
| **`SquadController`는 개별 브레인 바깥** — 블랙보드(`SlotAngle`, 공격 토큰)로만 허가 | 스쿼드가 트리 안에 들어가면 각 노드의 독립 테스트가 깨진다 (지침서 8.7) |
| **`EnemyBehavior`는 `maxActiveDuration`으로 반드시 끝난다** — 조건 대기만으로 끝나는 노드 금지 | 적이 영원히 멈추거나 파르르 떠는 것 방지 (지침서 3장) |
| **히트스턴 종료 → 즉시 재판단** — `EnemyBrain.GetIntent`가 `IsHitStunned` 이탈 프레임에 `[reset]` 강제 | 히트스턴 후 "텀"이 사실상 무한 콤보가 됨 (지침서 5장) |
| **적 성향은 `EnemyArchetype` 가중치만** — 새 행동·셸 코드 없이 | 같은 목록으로 성격 다른 적 (지침서 3장 니치) |
| **`use8DirectionSnap`: 플레이어 켬 / AI 끔** | AI는 임의 각도로 궤도를 향해야 함 |
